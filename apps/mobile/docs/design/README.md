These are visual references, not fully implemented or usability-tested screens.
`Saylo` wordmarks and any obsolete `Story` labels inside an image are placeholders;
new product copy must use the current `Topic → Version → Attempt` model.

The accepted transferable visual direction is editorial, adult, private, and calm:

- Newsreader for limited expressive moments;
- Inter for interface text;
- Midnight for structure;
- Apricot for active speaking behavior;
- Ivory for the canvas;
- restrained informational accents;
- no corporate performance dashboard or beginner-game grammar.

Older Cobalt, Neutral Studio, monochrome, onboarding, profile, and Mirror-skin
iterations are stored in `docs/archive/2026-08-design-explorations/` and are not
current guidance.
