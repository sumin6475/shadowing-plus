# Weekly Sync — Monday agenda (45–60 min)

Ops Scribe pre-fills sections 1–3 before the meeting, so the time is for **deciding**, not gathering. Copy per week. *(from the team playbook §4)*

    SHADOWING PLUS — WEEKLY SYNC
    Date: ____   Last week's goal: ____   Hit it? Y / N

    1. The 3 metrics (5 min)            ← always first   [Ops Scribe pre-fills]
       ① Weekly Active Learners: ___  (last ___)
       ② Week-1 retention:       ___% (last ___)
       ③ "Very disappointed":    ___% (n=___)
       One line: what moved / didn't?

    2. Check-in (5 min) — each person: "what I did / how I feel"

    3. Feedback (8 min) — Community: top-3 ranked  ·  Builder: what shipped

    4. Decisions (15 min)               ← the heart
       open questions → Sumin decides out loud + one-sentence why → write each down

    5. Next week (10 min) — one team goal (which metric) + one owned task each

    6. Blockers (5 min) — "what's stopping you?" → solve or assign

    7. Close (2 min) — one small win to celebrate  ·  next meeting time

**Rules:** start/end on time · every decision written down · every task = one owner + one date.
