## What these are — and what they are NOT

These are **reference material only.** They are **not** an installed skill (nothing
was added to `.claude/skills/`), and they are **not part of the build pipeline** —
nothing in `web/` reads them, no code imports them, no deploy touches them. They sit
here as vendored reading for the Growth lane. The one file that adapts them into
Shadowing Plus house rules is `../evidence-and-loops.md`; these four files are left
untouched so attribution stays clean.
