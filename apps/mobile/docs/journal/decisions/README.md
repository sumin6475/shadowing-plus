# Decisions (ADR) — 설계 결정 기록

되돌리기 비싼 결정만 여기 남긴다. 판단력의 증거는 선택 자체가 아니라 **비교의 기록**이다: 기각한 대안과 그 이유가 함께 있어야 비교가 실제로 일어났다는 게 남는다.

**언제 쓰나**: 결정을 뒤집는 비용 > 문서를 쓰는 비용일 때. 아키텍처, 데이터 모델, 외부 의존성, API 계약, 임계값. 쉽게 되돌릴 결정은 문서 없이 빠르게 간다 (모든 걸 문서화하는 것도 판단력 부족).

**파일명**: `NNNN-<슬러그>.md` (예: `0001-choose-vector-store.md`). 번호는 4자리 증가.

**형식**: `_TEMPLATE.md` 복사. 좋은 문서와 나쁜 문서의 차이는 **기각 이유의 구체성**이다.
- 나쁜 예: "Kafka는 오버엔지니어링이라 제외"
- 좋은 예: "현재 처리량(초당 N건)에서 Kafka의 운영 비용이 이점을 초과한다. 처리량이 10배가 되는 시점에 재검토한다"
