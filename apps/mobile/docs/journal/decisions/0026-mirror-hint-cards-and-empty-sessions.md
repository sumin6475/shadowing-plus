# ADR 0026 — Mirror 힌트: 표현 카드 + 자동 체크, 오늘의 표현 우선, 빈 세션은 저장 안 함

- **날짜**: 2026-09-26
- **스텝**: build 31 실기기 피드백 — Mirror 힌트·결과 화면
- **상태**: accepted (Sumin 결정, 2026-09-26)

## 맥락 (Context)
실기기에서 Hint(전구)를 켜면 "TODAY'S PHRASES — Ready phrases will appear here. For now, speak freely."만 나왔다. 힌트는 체크리스트 3단계를 끝낸 **Ready** 표현만 보여줬는데 Sumin의 표현은 38개 모두 Collected — 힌트가 한 번도 채워진 적이 없었다. 채워져도 정적인 칩 목록이라 할 수 있는 게 없었다. 같은 테스트에서 말없이 끝낸 세션이 "1s of speaking · No transcript captured."로 기록에 남았다.

MVP 문서의 제약: Mirror에서는 코칭·표현 추천 요청(서버/AI)을 돌리지 않는다. 음성 인식은 기기 안에서만.

## 검토한 선택지 (Options)
- **힌트 방식**: ① 표현 카드 + 말하면 자동 체크(기기 안 매칭), 탭하면 뜻·내 문장 ② 말할 거리 질문 카드(셔플) ③ 둘 다(상단 전환)
- **카드에 들어갈 표현**: ① 오늘의 표현(홈의 5개 픽) 먼저, 모자라면 Ready ② Ready만(기존)
- **말이 하나도 인식되지 않은 세션**: ① 저장하지 않음 ② 지금처럼 저장

## 결정 (Decision)
표현 카드 + 자동 체크 · 오늘의 표현 우선(+Ready, "Use it in the mirror"로 온 표현이 맨 앞) · 빈 세션은 저장하지 않고 결과 화면에서 "No words caught." + Try again.

## 기각 이유 (판단의 증거)
- 질문 카드(②)는 막힐 때만 쓸모 있고, 앱의 루프(저장 → 체크리스트 → 실제로 말하기)와 이어지지 않는다. 자동 체크는 그 루프의 마지막 칸("실제로 써 봤나")을 처음으로 측정한다.
- Ready만(②)은 지금 사용자에게 빈 화면이다. 오늘의 표현 + Ready는 합치면 저장한 모든 표현이 후보라, 표현이 하나라도 있으면 덱이 비지 않는다.
- 빈 세션 저장(②)은 기록 목록과 합계를 오염시킨다 — 9/20에 Sumin이 부풀려진·빈 세션을 직접 지운 적이 있다. 녹음은 결과 화면에 있는 동안 Listen back으로 들을 수 있다.
- 매칭을 AI로 하지 않은 이유: MVP 제약(요청 없음) + 실시간 반응이 필요. 순수 함수 `lib/phrase-use.ts`(축약형·동사 변화·my/your·sb/sth 자리표시자 허용, 순서·인접은 엄격)로 테스트 가능하게.

## 결과 (Consequences)
- 사용 여부는 **저장하지 않는다**(스키마 변경 없음). 결과 화면과 라이브 화면만 안다 — 기록(My records)에는 "Phrases used"가 없다.
- 녹음 중에는 iOS가 햅틱을 막는다(오디오 세션이 opt-in하지 않는 한) → 피드백은 체크 애니메이션·토스트·배지로.
- 덱은 카드가 있으면 기본으로 열린다(학습자가 먼저 닫으면 그대로).
- 매칭은 규칙 기반이라 틀릴 수 있다: 불규칙 복수("movies" ↔ "movie"), "agreed" ↔ "agree", 슬래시 대안 안의 두 단어 표현.
- **재검토 조건**: 실제로 말했는데 체크가 안 된다는 피드백이 반복되면 매칭을 느슨하게(단어 1개 끼어듦 허용 등). 사용 기록을 Profile이나 표현 상세에서 보고 싶어지면 `talk_sessions`에 사용 표현 id를 저장하는 마이그레이션. 빈 세션 녹음을 잃어서 아쉽다는 신호가 오면 저장 옵션 재검토.
