# Phase 1 설계 — 랜딩 / 데모 / Waitlist (2026-07-10)

> ver2.0 plan. 리서치 근거: `2026-07-10-productization-research-brainstorm.md`.
> 목적 2개: (1) 수요 검증 (freemium 진행 여부), (2) **전용 앱 투자 판단 데이터 수집**.

---

## 0. 핵심 스탠스

- **전용 앱 판단은 waitlist 데이터로.** 단, Sumin이 앱에서 원하는 카드 스와이프
  애니메이션과 island 비주얼은 PWA로 구현 가능 → 네이티브 전용 가치(iOS 네이티브 푸시,
  앱스토어 노출, 백그라운드 오디오, 오프라인)에 대한 수요만 waitlist에서 측정.
- **aesthetic이 곧 마케팅.** 스와이프 카드·island 맵을 PWA에 먼저 만들고, 그 화면을
  랜딩 히어로와 SNS 재료로 쓴다.
- **보여주기 > 설명하기.** 랜딩의 중심은 카피가 아니라 작동하는 데모.

## 1. 랜딩에서 강조할 것 (리서치 → 메시지 우선순위)

리서치의 갭 3개를 전환 관점에서 재배열:

| 순위 | 메시지 | 왜 이 순서 |
| :---- | :---- | :---- |
| 히어로 | **"네 콘텐츠가 네 코스다"** — 좋아하는 팟캐스트/영상을 올리면 쉐도잉 코스가 됨 | 3초 안에 이해됨. 중급자의 진짜 고통("앱 커리큘럼은 유치하고, 진짜 콘텐츠는 너무 어렵다" = plateau)을 정면으로 침 |
| 2막 | **"복습이 너를 찾아온다"** — 북마크한 문장이 메신저로 도착, 답장으로 복습 끝 | 경쟁 전무(화이트 스페이스). 리텐션 약속 = "작심삼일 방지"로 번역 |
| 3막 (티저) | **"네가 실제 쓰는 말부터"** — L1 표현 프로파일 (Quick learning) | 가장 novel하지만 아직 안 만들어짐 → 히어로에 걸면 과약속. "founding member 선공개"로 waitlist 유인책화 |
| 비주얼 시그니처 | **Language island 맵** — 주제 섬들이 쌓이는 지도 | 카피가 아니라 그림으로 차별화. 브랜드 아이덴티티 후보 |

히어로 카피 방향 (시안, 타깃 언어별 현지화 전제):
- 주: "Stop studying someone else's sentences." / "Your favorite podcast is your best textbook."
- 부: "Upload anything → shadow it line by line → reviews find you in your messenger."

**안 할 것:** 기능 나열식 랜딩(경쟁사 전부 이 패턴), "AI-powered" 남발, 초기에 가격표
노출(waitlist 단계에선 불필요).

## 2. 데모 설계 (3층)

| 층 | 내용 | 비용 | 역할 |
| :---- | :---- | :---- | :---- |
| D1 — 인라인 데모 | 랜딩 히어로에 **실제 플레이어 임베드**: 언어별 사전 처리 샘플 클립 1개, 문장 하이라이트·A-B 루프·북마크까지 조작 가능 (read-only, 가입 불필요) | $0 (사전 처리) | 3초 안에 "아 이거구나" |
| D2 — 메신저 목업 | Review 메시지가 도착해서 버튼으로 채점되는 장면의 애니메이션 목업 (실제 발송 아님) | $0 | 화이트 스페이스 기능을 시각화 |
| D3 — "내 클립으로 해보기" | **가입 없이 5분짜리 본인 파일 1개 업로드 → 실제 파이프라인 → 결과 체험.** IP당 1회, Groq 라우팅 | 회당 ~$0.01 (Groq $0.111/hr × 5분) | 최고 전환 무기. "내 콘텐츠로 된다"를 증명하는 유일한 방법 |

D3가 이 랜딩의 승부수. 경쟁사 누구도 가입 전에 이걸 못 보여줌 (라이선스 카탈로그거나
확장프로그램이라). 비용은 1,000명이 써도 $10. 남용 방어: 5분 제한 + IP당 1회 +
Turnstile(무료 캡차).

샘플 클립 소싱 (D1): 언어별 1개, CC-BY 팟캐스트/강연 또는 자체 녹음. 저작권 확실한
것만 (decision-log 미결 항목 해소 필요).

## 3. Waitlist 설계 — 이메일 수집이 아니라 리서치 도구

### 폼 (이메일 + 4문항, 30초 컷)

1. **배우는 언어 / 모어(L1)** → 다국어 우선순위 + Quick learning 언어 커버리지 결정
2. **"뭘 올리고 싶어?"** (팟캐스트 / YouTube / 드라마·영화 / 강의 / 내 녹음) →
   콘텐츠 모델 검증. **YouTube 응답률이 높으면 iframe-embed 방식(리서치 §4)의
   우선순위가 올라감** — 합법 경로로 풀 가치가 있는지의 데이터
3. **"주로 어디서 쓸 것 같아?"** (폰-이동중 / 폰-집 / 데스크탑) + **"앱스토어 앱이면
   설치할래?"** (예/아니오/PWA도 상관없음) → **전용 앱 판단의 직접 데이터**
4. **"지금 뭘 쓰고 있고 뭐가 불만이야?"** (자유 텍스트, 선택) → 포지셔닝 검증 + 랜딩
   카피 소재 (유저의 언어로 다시 쓰기)

저장: Supabase 테이블 1개 (`waitlist`). 신규 인프라 없음. 확인 메일은 Resend 무료 티어.

### 전환 장치

- **Founding member 프레임**: 선착 100명 = 평생 50% 할인 + Quick learning 선공개 +
  이름 크레딧. (가격 미공개 상태에서도 "할인 약속"은 유효)
- **리퍼럴로 순번 상승**: 공유 링크당 앞으로 N칸. 바이럴 루프 표준 패턴.
- D3 체험 완료 직후가 최적 타이밍: "이 클립 저장해두고 싶으면 waitlist 등록" —
  체험 결과물을 인질(?)로 한 자연스러운 CTA.

### 전용 앱 판단 기준 (사전에 숫자로 박아두기)

| 신호 | 임계값 (제안) | 판단 |
| :---- | :---- | :---- |
| waitlist 규모 | 500+ (유료 광고 없이) | 수요 자체 검증 |
| 모바일 사용 의향 | 60%+ | 모바일 우선 확정 |
| "앱스토어면 설치" 응답 | 50%+ **그리고** iOS 비중 높음 | 네이티브(혹은 RN/Expo) 투자 |
| 그 외 | — | PWA 폴리시 유지 + 스와이프/island를 PWA에서 |

숫자는 시작점 제안일 뿐 — 중요한 건 **판단 기준을 데이터 수집 전에 확정**해서
사후 합리화를 막는 것.

## 4. 트래픽 소스 (랜딩은 만들어도 아무도 안 옴 문제)

- **Build in public**: Sumin의 기존 LinkedIn 브랜드 시스템(캐러셀·콘셉트 포스터)으로
  개발 과정 자체를 콘텐츠화. 이 repo의 히스토리가 재료 (builder-story-snapshot 활용 가능).
- 언어 학습 커뮤니티: r/languagelearning, HN Show, 언어별 학습 디스코드 — D3 데모가
  있어야 반응이 옴 ("또 하나의 앱"이 아니라 "바로 해볼 수 있는 것").
- 타이밍: 랜딩 공개는 D1+waitlist만으로 시작 가능, D3 완성 후 커뮤니티 포스팅.

## 6. 결정 & 미결

**결정 (2026-07-10):**

- **Island 비주얼 = 카드 그리드.** SRS 스와이프 카드와 같은 디자인 언어로 통일 —
  "카드"가 앱 전체의 비주얼 시스템이 됨 (island 카드 = 카드 묶음의 표지 개념으로
  확장 가능). 지도풍은 기각.
- **리네이밍 확정.** "Shadowing Plus"는 기능 확장(L1-first, island)을 담기에 좁음.

**네이밍 진행 상황 (도메인 실측 2026-07-10, Vercel):**

| 후보 | 도메인 | 상태 | 노트 |
| :---- | :---- | :---- | :---- |
| Islang | islang.app | **가용, $9.99/yr** | island + language + slang 삼중 의미. 발음 모호성("이슬랭/아이슬랭")이 약점 |
| Lingloop | lingloop.app | **가용, $9.99/yr** | 제품 본질(복습 루프)과 정합, 발음 쉬움. 다소 기능적/generic |
| unison/mimiq/sotto/parlo/murmur/attune/echoloop 등 | .app/.com | 전부 선점 | 좋은 일반명사는 소진 — 변형 조어 필요 |

네이밍 방향 4개 중 선택 후 심화 탐색: (A) island 세계관 (B) 루프/리텐션
(C) 쉐도잉 행위(echo/unison 계열 조어) (D) 무의미 고유명사 (Duolingo/Anki 방식).

**미결:**

- 히어로 카피 확정 (waitlist 단계에선 EN 하나로 시작 권장)

- waitlist → 베타 초대 흐름 (수동 배치 초대면 충분한지)
