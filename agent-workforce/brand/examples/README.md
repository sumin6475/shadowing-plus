# examples/ — winners only

The final asset goes here **only after you've blessed it as a win.** Its recipe (how to reproduce it) goes in `../style.md`.

- ✅ In: the actual approved landing mockups, demo clips, social visuals.
- ❌ Out: trials, drafts, "maybes," anything you didn't pick.

Keeping this folder ruthless is what makes it a real style reference instead of a junk drawer. Name files so the recipe is findable, e.g. `2026-07-02-landing-hero-v3.png`.
