# Postmortem — 첫 실행 코치마크의 탭바 스텝이 엉뚱한 곳을 뚫음

- **날짜**: 2026-09-10
- **스텝**: 첫 로그인 온보딩(딤 + 스포트라이트) 구현
- **심각도**: P3 (신규 기능, 출시 전)

## 실패 현상
4단계 코치마크 중 마지막 "탭바" 스텝에서, 뚫어 놓은 구멍이 탭바가 아니라 그
**위쪽 빈 영역**(Today 카드 상단 + 캡처 FAB)에 생겼다. 그리고 진짜 네이티브
탭바는 **딤이 전혀 걸리지 않은 채** 정상 밝기로 보였다.

또한 2·3번 스텝(This week 카드, 프로필 아바타)이 **말없이 건너뛰어져서** 점
인디케이터가 1 → 4로 튀었다.

## 가설
- **H1**: 탭바 사각형 계산(`insets.bottom` 기반)이 틀렸다.
- **H2**: RN `Modal`이 `NativeTabs`의 UITabBar 위에 뜨지 않는다 — 즉 애초에 탭바는 딤 대상이 아니다.
- **H3**: 스킵은 `TourTarget` 등록 실패다.
- **H4**: 스킵은 가시성 판정(`fits()`) 이 너무 엄격해서다.

## 검증 방법과 결과
iOS 26 시뮬레이터(iPhone 17 Pro, 402×874pt)에서 스크린샷으로 직접 확인.

- H1 → 부분 사실이지만 원인 아님.
- H2 → **확정**. 딤이 깔린 상태에서 탭바의 라벨·아이콘·유리 캡슐이 전부 원래
  밝기 그대로였다. `expo-router`의 `NativeTabs`는 진짜 `UITabBar`이고, 탭 화면
  안에서 present한 modal 위에 그려진다.
- H3 → 기각. 등록은 되고 있었다.
- H4 → **확정**. 두 가지가 겹쳤다.
  - `top = insets.top + 24`(=83)로 잡았는데 Today 헤더의 아바타는 y≈71 →
    `rect.y >= top` 에서 탈락.
  - `MIN_VISIBLE`을 절대값 72pt로 두어서 **높이 44pt짜리 아바타는 영원히 통과 불가**.
  - Today(복습) 카드는 스크롤 뷰의 **마지막 요소**라 최대로 스크롤해도 탭바 위에
    온전히 들어올 수 없다(콘텐츠 여유가 ~124pt뿐).

## 근본 원인
플랫폼을 상대로 싸웠다. "딤은 화면 전체를 덮는다"를 전제로 마스크를 설계했는데,
네이티브 탭바는 그 전제 밖에 있다. 그리고 가시성 판정을 **타깃의 크기와 무관한
절대값**으로 써서, 작은 타깃과 화면 끝에 붙은 큰 타깃이 둘 다 조용히 탈락했다.

## 수정
1. **탭바 스텝은 구멍을 뚫지 않는다.** 화면 전체를 딤으로 덮기만 하면, 딤이 안
   걸리는 탭바가 저절로 스포트라이트가 된다. 플랫폼 동작을 이용하는 쪽으로 뒤집음.
   (`ResolvedStep.rect: TargetRect | null`, `null` = 구멍 없음)
2. `top = insets.top`, 가시성은 **타깃 높이 대비**로:
   `visible >= Math.min(rect.height, MIN_VISIBLE)`.
3. **등록된 스텝은 절대 조용히 버리지 않는다.** 프레이밍이 안 되면 같은 문구를
   구멍 없이 보여준다(`{ rect: null }`). 아무것도 못 가르치는 것보다 낫다.
4. `review` 스텝의 타깃을 Today 카드 → **This week 카드**로. 스크롤 0에서 항상
   온전히 보이므로 스크롤-인투-뷰에 의존하지 않는다.

## Before / After
- Before: 4스텝 중 2스텝이 조용히 스킵, 마지막 스텝은 엉뚱한 영역을 하이라이트.
- After: 4스텝 모두 표시, 각 스텝이 의도한 컨트롤을 가리킴. 완료 후
  `saylo.tour.today.v1 = "1"` 저장 확인, 재실행 시 다시 뜨지 않음 (시뮬레이터 검증).

## 회귀 방지
자동 테스트 없음 — RN 레이아웃 측정은 순수 함수가 아니라 vitest 대상이 아니다.
대신 **불변식을 코드에 박았다**: 등록된 스텝은 `null`을 반환할 수 없고(항상
`{rect}` 아니면 `{rect: null}`), 가시성 기준은 타깃 높이에 상대적이다. 다음에
Today 레이아웃이 바뀌면 스텝이 사라지는 대신 구멍 없는 카드로 degrade된다.

**남는 플랫폼 사실**: `NativeTabs`(UITabBar)는 RN `Modal` 위에 그려진다. 탭바를
가리거나 마스킹해야 하면 `NativeTabs`의 `hidden`으로 숨기는 수밖에 없다.
