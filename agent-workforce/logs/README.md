# logs/ — daily "dreaming" trail

End each working day with a compaction: what happened, what was decided, what broke. Then **promote durable rules / decisions** up into [`../MEMORY.md`](../MEMORY.md) (and `../CLAUDE.md` if it's a standing rule). *(operating system → "Manage the Dumb Zone")*

- **Naming:** one file per day, `YYYY-MM-DD.md`.
- Notion's Daily Logs DB is the live home once set up; this is the local trail + memory substrate.
- Never delete a log — it's the audit trail.
