# handoffs/ — Ralph-loop relay docs

Sequential work moves between phases / agents as a short doc here, so each receiver starts with a **fresh** context (anti–Dumb-Zone). Notion is the live home once set up; this is the local trail.

- **Template:** [`../templates/handoff.md`](../templates/handoff.md)
- **Naming:** `YYYY-MM-DD-<from>→<to>-<topic>.md`  (e.g. `2026-06-22-plan→build-firstscreen.md`)
- Keep them short; always include **evidence** before marking a leg done.
