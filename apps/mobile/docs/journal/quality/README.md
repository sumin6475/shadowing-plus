# Quality — 품질 기준 + 회귀 기록

품질을 느낌이 아니라 숫자로 확인한 기록. 두 가지가 산다:

- **`quality-bar.md`** — 상시 품질 기준 문서. 출시 조건, 지표 정의, 심각도 분류, 알려진 한계. 살아있는 문서 (기준선이 나오면 채운다).
- **`YYYY-MM-DD-score-run.md`** — 테스트/eval을 돌릴 때마다의 점수 스냅샷. 버전 간 비교가 남도록 (예: v1 0.60 → v2 0.72 → v3 0.81).

**회귀 스위트의 정본은 프로젝트의 테스트/eval 폴더다.** 이 폴더는 그 결과의 시간순 기록과 판정 기준을 담는다.

**핵심 습관**: 버그를 고치면, 그 버그를 잡았을 케이스를 반드시 회귀 스위트에 추가한다. 이 규칙 하나가 회귀 방지의 대부분을 담당한다. (연결되는 포스트모템의 "재발 방지" 항목과 짝.)

**증명하는 것**: "이 사람은 자기 시스템의 실패 모드를 알고, 개선을 느낌이 아니라 숫자로 확인한다."
